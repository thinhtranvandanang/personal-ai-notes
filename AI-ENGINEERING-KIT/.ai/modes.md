# AI Working Modes

## Discovery mode
Explore the problem, ask questions, identify unknowns. Do not implement.

## Design mode
Produce requirements, diagrams, schemas, UI specifications, and trade-off analysis. Do not implement unless explicitly requested.

## Prototype mode
Build a limited UI or proof of concept using sample data. Clearly label mock behavior.

## Implementation mode
Implement only the approved scope and design.

## Review mode
Inspect code, security, tests, and documentation. Report findings before making broad changes.

## Session-close mode
Summarize progress and update project tracking documents.
