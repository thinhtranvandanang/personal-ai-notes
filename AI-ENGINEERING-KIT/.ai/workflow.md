# AI Workflow

For each task:

1. Read `AGENTS.md`, `PROJECT_STATUS.md`, and task-specific documents.
2. Restate the goal, scope, constraints, and acceptance criteria.
3. Identify missing information and assumptions.
4. Propose a small implementation plan.
5. Wait for approval when decisions or risks require it.
6. Make a focused change.
7. Run relevant checks and report actual results.
8. Update documentation and status.

Do not combine unrelated phases into one large implementation task.
